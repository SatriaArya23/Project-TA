# Aset Statis Opsional (Branding)

Berkas gambar milik perusahaan studi kasus (`logo-hotdog.png`, `foto-anemon.jpg`, `foto-karang.jpg`) sengaja **tidak disertakan** di repositori publik ini.

Saat memasang dashboard di server produksi atau uji secara lokal, letakkan aset logo/latar belakang yang diizinkan ke dalam folder ini. Jika berkas belum ada, fungsi pembantu `aset()` tetap berjalan aman tanpa menimbulkan galat pada aplikasi maupun pengujian.
